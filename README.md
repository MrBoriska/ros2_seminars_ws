# Практический курс семинаров по робототехнике в ROS 2 Humble

Учебный репозиторий содержит методические указания, примеры программного кода, модели роботов и сценарии моделирования для цикла практических семинаров по робототехнике на базе операционной системы роботов **ROS 2 Humble Hawksbill** и симулятора **Gazebo**.

---

| Семинар | Тема | Основные изучаемые концепции |
| :--- | :--- | :--- |
| **[Семинар №0](Семинар%200.md)** | Базовое знакомство с Linux и сетями | Командная оболочка Bash, права доступа, SSH, процессы, системные службы Systemd, базовые понятия Docker. |
| **[Семинар №1](Семинар%201.md)** | Знакомство с фреймворком ROS 2 | Граф вычислений ROS 2 (узлы, топики, типы сообщений), формат описания роботов URDF (древовидная топология), `joint_state_publisher` vs `robot_state_publisher`, робот R2D2. |

## 🏆 Модульно-рейтинговая система и индивидуальные задания (на 54 балла)

Семестр разделен на **два контрольных модуля**:
* **Модуль 1 (Семинары 0 и 1):** Основы Linux, Docker, граф ROS 2, URDF-моделирование и навигация мобильного робота.
* **Модуль 2 (Семинары 2 и 3):** Физическая симуляция в Gazebo Classic, дифференциальный привод, сенсоры (LIDAR/камера/IMU) и мобильный манипулятор KUKA YouBot.

### Траектории оценивания:
1. **Стандартный трек (от 35 до 45 баллов):** Сдача лабораторных отчетов по материалам семинаров (оценка за модуль рассчитывается как среднее арифметическое двух семинаров: макс. 45 баллов).
2. **Продвинутый трек (54 балла — «Отлично»):** Выполнение одного из 15 индивидуальных проектов повышенной сложности по каждому модулю (всего 2 проекта за семестр) с подтверждением работы через **бинарную запись ROS 2 Bag (`.db3`/`.mcap`)**:
   👉 **Полный банк заданий и регламент сдачи: [ИНДИВИДУАЛЬНЫЕ_ЗАДАНИЯ.md](ИНДИВИДУАЛЬНЫЕ_ЗАДАНИЯ.md)**.

## 🚀 Быстрый старт

Вся кодовая база репозитория полностью изолирована и готова к запуску «из коробки» через Docker.

### Вариант 1. Запуск через VS Code Dev Containers (Рекомендуемый)

Если вы работаете в Visual Studio Code:
1. Установите расширение **Dev Containers** (`ms-vscode-remote.remote-containers`).
2. Откройте папку репозитория в VS Code.
3. В правом нижнем углу появится всплывающее окно — нажмите **Reopen in Container** (или нажмите `Ctrl+Shift+P` и выберите команду `Dev Containers: Reopen in Container`).
4. VS Code автоматически соберет контейнер на базе `osrf/ros:humble-desktop-full`, установит все зависимости, пробросит графический сервер X11 для RViz/Gazebo и соберет воркспейс `colcon build`.

### Вариант 2. Запуск через терминал с помощью Docker

Для быстрого интерактивного запуска в консоли Linux:
```bash
./run_in_docker.sh
```
Скрипт автоматически настроит доступ к X11-серверу (`xhost`), пробросит графику и переменные окружения, смонтирует текущий воркспейс и откроет терминал со всеми активированными переменными ROS 2.

### Вариант 3. Нативная установка на Ubuntu 22.04 LTS

Если у вас уже установлена ОС Ubuntu 22.04 LTS и ROS 2 Humble Desktop:
```bash
# 1. Установка всех необходимых системных пакетов и симулятора Gazebo
./deploy/install_ros2_humble_deps.sh

# 2. Настройка изоляции топиков и автозагрузки окружения в ~/.bashrc
./deploy/setup_workspace.sh

# 3. Сборка рабочего пространства
source /opt/ros/humble/setup.bash
colcon build --symlink-install
source install/setup.bash
```

* **Базовая ОС**: Ubuntu 22.04 LTS (Jammy Jellyfish)
