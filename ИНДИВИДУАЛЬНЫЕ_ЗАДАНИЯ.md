# Индивидуальные задания повышенной сложности (на оценку «Отлично» — 54 балла)

В данном документе представлены темы и технические требования к **индивидуальным практическим проектам**, позволяющим получить максимальную оценку (**54 балла**) за каждый из учебных модулей курса робототехники в ROS 2 Humble.

---

## 🏛️ Регламент модульно-рейтинговой системы

Семестровый курс разделен на **два контрольных модуля**:

```
                              ┌────────────────────────────────────────────────────────┐
                              │             Итоговая оценка за семестр                 │
                              │           (Среднее арифметическое модулей)             │
                              └───────────────────────────┬────────────────────────────┘
                                                          │
                       ┌──────────────────────────────────┴──────────────────────────────────┐
                       ▼                                                                     ▼
    ┌──────────────────────────────────────┐                              ┌──────────────────────────────────────┐
    │     МОДУЛЬ 1 (Семинары 0 и 1)        │                              │     МОДУЛЬ 2 (Семинары 2 и 3)        │
    ├──────────────────────────────────────┤                              ├──────────────────────────────────────┤
    │ Темы: Linux, Docker, ROS 2 Core,     │                              │ Темы: Gazebo Classic, ODE динамика,  │
    │ URDF, XACRO, кинематика мобильных    │                              │ KUKA YouBot (Mecanum + 5-DOF рука),  │
    │ роботов, TF2, навигация в симуляторе.│                              │ сенсоры, мобильная манипуляция.      │
    ├──────────────────────────────────────┤                              ├──────────────────────────────────────┤
    │ Стандартный трек: Семинары 0 и 1     │                              │ Стандартный трек: Семинары 2 и 3     │
    │ ➔ Оценка от 35 до 45 баллов.         │                              │ ➔ Оценка от 35 до 45 баллов.         │
    │                                      │                              │                                      │
    │ Продвинутый трек:                    │                              │ Продвинутый трек:                    │
    │ 1 Индивидуальное задание Модуля 1    │                              │ 1 Индивидуальное задание Модуля 2    │
    │ ➔ 54 БАЛЛА ЗА МОДУЛЬ 1               │                              │ ➔ 54 БАЛЛА ЗА МОДУЛЬ 2               │
    └──────────────────────────────────────┘                              └──────────────────────────────────────┘
```

### Правила получения оценки «Отлично» (54 балла):
1. Выполнение индивидуального задания по модулю **освобождает от необходимости сдавать базовые лабораторные отчеты** по соответствующим семинарам.
2. Чтобы получить 54 балла за весь семестр, студент выполняет **2 индивидуальных задания**:
   * Одно задание из **Блока Модуля 1** (сдается в середине семестра).
   * Одно задание из **Блока Модуля 2** (сдается в конце семестра).
3. Номер варианта в каждом модуле определяется строго по номеру студенческого билета / зачетной книжки (`STUDENT_ID`):
   $$\text{Вариант} = (\text{STUDENT\_ID} \pmod{15}) + 1$$
4. Все физические и кинематические параметры задачи рассчитываются по индивидуальным формулам от `STUDENT_ID`.

## 🛡️ Требования к валидации индивидуальных заданий

> [!IMPORTANT]
> Данные требования относятся **исключительно к индивидуальным заданиям на 54 балла**! Для стандартных отчетов по семинарам (на оценку до 45 баллов) запись rosbag не требуется — там достаточно скриншотов и листингов.

Учитывая удаленный формат работы, оценка **54 балла** за индивидуальный проект выставляется при выполнении двух условий:

1. **Индивидуализация параметров по номеру студенческого билета (`STUDENT_ID`)**:
   * Все числовые параметры задачи (радиусы, линейные скорости, дистанции упреждения и амплитуды) рассчитываются по формулам, приведенным в начале каждого блока заданий.
   * Если в коде или симуляции использованы чужие или произвольные числа — работа отклоняется.

2. **Обязательный бинарный архив ROS 2 Bag (`.db3` или `.mcap`)**:
   * Для подтверждения реального запуска симуляции к отчету прикладывается записанный лог топиков длительностью **не менее 30 секунд**:
     ```bash
     ros2 bag record /tf /clock /cmd_vel /odom /youbot/joint_states -o my_run.bag
     ```
   * *Почему этого достаточно:* Текстовые нейросети не способны сгенерировать бинарный файл базы данных SQLite3 с сотнями тысяч сериализованных сообщений, содержащих реальный микросекундный шум физического движка ODE. Записанный росбаг служит 100% подтверждением самостоятельного запуска кода студентом.

# 📦 Блок заданий Модуля 1 (по материалам Семинаров 1 и 2)

**Базовая платформа:** Дифференциальный колесный робот ([`basic_mobile_robot`](src/basic_mobile_robot/)) в ROS 2 и Gazebo Classic.  
**Среда выполнения:** ROS 2 Humble, `rclpy`, RViz2, Gazebo Classic.

### Индивидуальные параметры (рассчитываются каждым студентом):
```python
STUDENT_ID = 20240185  # Ваш номер студенческого билета
PARAM_R = 0.60 + (STUDENT_ID % 7) * 0.10   # Базовый радиус траектории (м): 0.60 ... 1.20
PARAM_V = 0.20 + (STUDENT_ID % 5) * 0.05   # Линейная скорость (м/с): 0.20 ... 0.40
PARAM_L = 0.25 + (STUDENT_ID % 4) * 0.05   # Дистанция упреждения (м): 0.25 ... 0.40
```

### Список вариантов Модуля 1:

| Вариант | Название алгоритма | Сенсорный вход | Требование к алгоритмическому узлу |
|:---:|:---|:---|:---|
| **1** | **Траекторный регулятор Pure Pursuit** | `/odom` | Реализовать алгоритм слежения за ломаной траекторией из 5 путевых точек с вычислением кривизны дуги $\gamma = \frac{2\sin\alpha}{L}$ и динамическим упреждением `PARAM_L`. Ошибка слежения $\le 5$ см. |
| **2** | **Линеаризация обратной связью (Feedback Linearization)** | `/odom` | Метод вынесенной точки: расчет скоростей тележки $[v, \omega]$ для удержания точки на плече $d=0.15$ м на траектории «восьмерка» (лемниската Бернулли масштаба `PARAM_R`). |
| **3** | **Полярный регулятор парковки (Astolfi Controller)** | `/odom` | Нелинейный регулятор стабилизации позы: точный заезд робота задним ходом в целевую позу $(x_d, y_d, \theta_d)$ из начального положения со смещением $1.5$ м. Ошибка по углу $\le 3^\circ$. |
| **4** | **ПИД-движение вдоль стены по лидару (Wall Follower)** | `/scan` | ПИД-регулятор угловой скорости $\omega$ по массиву лучей 2D-лидара для движения вдоль стены коридора на фиксированном расстоянии `PARAM_L` при скорости `PARAM_V`. |
| **5** | **Сглаживание пути кубическими сплайнами** | `/odom` | ROS 2 сервис: прием 4 дискретных точек, расчет параметрического кубического сплайна $C^1$-гладкости и генерация временного профиля с лимитом центростремительного ускорения $v^2/R \le 0.5$ м/с$^2$. |
| **6** | **Следование за виртуальным лидером (Leader-Follower)** | TF2 буфер | Расчет вектора скорости ведомого робота для строгого удержания дистанции `PARAM_R` и ракурса $45^\circ$ относительно подвижного фрейма `leader` через буфер `tf2_ros`. |
| **7** | **Движение по замкнутой кардиоиде** | `/odom` | Аналитическое профилирование скоростей $[v(t), \omega(t)]$ для движения дифференциальной тележки по замкнутой кардиоиде $r = \text{PARAM\_R}(1 - \cos\varphi)$ с постоянной скоростью дуги `PARAM_V`. |
| **8** | **Реактивный объезд препятствий (Потенциальные поля - APF)** | `/scan`, `/odom` | Алгоритм искусственных потенциальных полей: расчет силы притяжения к цели и сил отталкивания от препятствий лидара. Успешный объезд 2 цилиндров без застревания в локальных минимумах. |
| **9** | **Дифференциальная одометрия с нуля (Dead Reckoning)** | `/joint_states` | Численное интегрирование позы робота по тикам колес (сопоставление методов Эйлера и Рунге-Кутта 2-го порядка). Вещание своего TF-фрейма `my_odom` и сопоставление дрейфа с `/odom`. |
| **10** | **Следование по кривым Дубинса (Dubins Paths)** | `/odom` | Аналитическое построение кратчайшего пути между двумя позами при лимите радиуса поворота $R_{min} = \text{PARAM\_R}$ (типы RSL/LSR) и отработка траектории регулятором в Gazebo. |
| **11** | **Лидарное следование за подвижным объектом (Target Follower)** | `/scan` | Кластеризация лучей 2D-лидара в секторе $\pm 60^\circ$ с фильтрацией шума. ПД-регулятор линейной и угловой скорости для плавного следования за препятствием со строгим удержанием дистанции `PARAM_L` при скорости до `PARAM_V`. |
| **12** | **Нелинейный траекторный регулятор Канаямы (Kanayama Controller)** | `/odom` | Регулятор слежения за опорной позой с доказанной устойчивостью по Ляпунову: преобразование ошибки в базис робота $\mathbf{e} = R(-\theta)(\mathbf{p}_r - \mathbf{p})$ и расчет $[v, \omega]$ для стабилизации на траектории «восьмерка» масштаба `PARAM_R`. |
| **13** | **Автоматическое экстренное торможение (AEB)** | `/scan`, `/odom` | Алгоритм расчета времени до столкновения ($TTC = d / v$): движение на скорости `PARAM_V` и автоматическое построение безопасного профиля замедления при обнаружении внезапного препятствия. |
| **14** | **Архимедова спираль с лимитом ускорения** | `/odom` | Развертывание спирали $r = b \cdot \varphi$ с непрерывным адаптивным ограничением центростремительного ускорения $a_n = v^2/R \le 0.4$ м/с$^2$ для предотвращения заноса колес. |
| **15** | **Конечный автомат патрулирования (FSM Patrol)** | `/odom`, `/scan` | Архитектура FSM: последовательный объезд 4 контрольных зон, круговой осмотр на точках, временная пауза и аварийная остановка при пересечении пути препятствием. |

# 🤖 Блок заданий Модуля 2 (по материалам Семинаров 2 и 3)

**Базовая платформа:** Мобильный манипулятор KUKA YouBot ([`youbot_description`](src/youbot_description/)) — омни-база (Mecanum) + 5-DOF манипулятор.  
**Среда выполнения:** ROS 2 Humble, `rclpy`, Gazebo Classic (физика ODE, гравитация), RViz2.  
**Основные топики робота:** `/youbot/cmd_vel` (скорость базы), `/youbot/odom` (одометрия), `/youbot/set_joint_trajectory` (управление рукой с `frame_id: 'world'`), `/youbot/scan` (лидар), `/youbot/joint_states` (состояния шарниров).

### Индивидуальные параметры (рассчитываются каждым студентом):
```python
STUDENT_ID = 20240185  # Ваш номер студенческого билета
ARM_AMPLITUDE = 0.10 + (STUDENT_ID % 5) * 0.02   # Амплитуда колебания руки (м): 0.10 ... 0.18
BASE_SPEED    = 0.25 + (STUDENT_ID % 4) * 0.05   # Скорость омни-базы (м/с): 0.25 ... 0.40
TARGET_RADIUS = 0.70 + (STUDENT_ID % 6) * 0.10   # Радиус омни-маневра (м): 0.70 ... 1.20
```

### Список вариантов Модуля 2:

| Вариант | Название алгоритма | Исполнительный узел | Алгоритмическая задача студента |
|:---:|:---|:---|:---|
| **1** | **Аналитическая IK руки YouBot по 3D-траектории** | Рука YouBot | Геометрический решатель обратной кинематики (IK) 5-DOF руки. Проводка схвата по пространственной 3D-спирали радиуса `ARM_AMPLITUDE` в воздухе Gazebo с погрешностью $\le 8$ мм. |
| **2** | **Координированная стабилизация фланца при езде** | База + Рука | Платформа YouBot едет по синусоиде. Манипулятор в реальном времени компенсирует перемещения базы, удерживая кончик схвата неподвижным в координатах `world` (дрейф $\le 15$ мм). |
| **3** | **Траекторный регулятор омни-базы по кривым Безье** | База YouBot | Регулятор слежения за параметрической кривой Безье с использованием омни-свойств колес (одновременная подача $V_x, V_y$ в `/youbot/cmd_vel`) и компенсацией бокового сноса. |
| **4** | **Орбитальный обход цели омни-платформой (Orbiting)** | База YouBot | Движение базы YouBot боком по окружности `TARGET_RADIUS` вокруг неподвижного объекта с поддержанием скорости `BASE_SPEED` и направления оси $X$ строго на центр объекта. |
| **5** | **Конечный автомат (FSM) операции Pick & Place** | База + Рука | Автономная миссия: подъезд базы к кубику по одометрии, раскладывание руки в позу захвата, наведение и сведение схвата над объектом (погрешность $\le 10$ мм), перенос на платформу робота и возврат в исходную точку. |
| **6** | **Демпфированный Якобиан (DLS) манипулятора** | Рука YouBot | Расчет матрицы Якоби $J(q)$ и реализация демпфированного псевдообращения $J^T(JJ^T + \lambda^2 I)^{-1}$ для безаварийного прохождения через вытянутые сингулярные позы руки без рывков. |
| **7** | **Квинтические сплайны (5th-order Splines) для руки** | Рука YouBot | Генератор траекторий со сплайнами 5-й степени ($C^2$-гладкость по ускорению) для минимизации динамических рывков (jerk) и вибраций звеньев манипулятора в симуляторе ODE. |
| **8** | **Омни-движение с удержанием взгляда на маяк** | База YouBot | Поступательное движение YouBot по окружности `TARGET_RADIUS`, при этом независимый угловой контур $\omega_z$ удерживает ориентацию корпуса строго на подвижную виртуальную цель. |
| **9** | **Прямая и обратная омни-кинематика 4 колес Mecanum** | База YouBot | Расчет матрицы омни-кинематики 4 колес с роликами под $45^\circ$: разложение $[V_x, V_y, \omega_z]$ на скорости колес $\omega_i$, публикация в `/youbot/wheel_speeds`, обратная реконструкция траектории по колесам и сопоставление дрейфа с `/youbot/odom`. |
| **10** | **Разрешение кинематической избыточности (Null-Space)** | База + Рука | Управление 8-DOF системой мобильного манипулятора (3-DOF омни-база + 5-DOF рука). Совместный якобиан $J \in \mathbb{R}^{3 \times 8}$: ведение схвата по 3D-траектории, а во вторичное подпространство $(I - J^+ J)$ — удержание шарниров около нейтральных углов. |
| **11** | **Динамическая стабилизация груза при маневрах базы** | База + Рука | Платформа YouBot совершает маневры с ускорением. Манипулятор с грузом, рассчитывая ускорение базы $\mathbf{a} = \dot{\mathbf{v}}$, динамически наклоняет схват против вектора кажущейся гравитации $(\mathbf{g} - \mathbf{a})$. |
| **12** | **Калибровка систематических погрешностей Mecanum (UMBmark)** | База YouBot | Калибровочный тест омни-платформы: проезд квадрата $2 \times 2$ м по и против часовой стрелки, вычисление систематических ошибок эффективных радиусов колес и программная коррекция. |
| **13** | **Искусственные потенциальные поля для руки YouBot** | Рука YouBot | Управление рукой YouBot в пространстве конфигураций с отталкиванием звеньев манипулятора от виртуальной цилиндрической зоны запрета при сближении с целевой точкой. |
| **14** | **Синхронное рисование по вертикальной стене** | База + Рука | Платформа YouBot равномерно движется вперед со скоростью `BASE_SPEED`, а манипулятор синхронно рисует фланцем синусоиду с амплитудой `ARM_AMPLITUDE` на виртуальной стене. |
| **15** | **ROS 2 Action Server навигации омни-базы** | База YouBot | Action `NavigateToPose`: движение омни-базы к цели, непрерывная публикация фидбека (дистанция, время), локальный объезд препятствия по лидару `/youbot/scan` и корректная отмена цели `cancel_goal`. |
