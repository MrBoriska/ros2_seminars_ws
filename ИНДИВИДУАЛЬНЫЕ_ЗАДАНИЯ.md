## Правила выбора варианта и требования к выполнению

1. **Выбор варианта:**
   Рекомендуемый способ выбора уникального варианта — по номеру студенческого билета / зачетной книжки (`STUDENT_ID`):
   $$\text{Вариант} = (\text{STUDENT\_ID} \pmod{15}) + 1$$
   Индивидуальные числовые параметры алгоритма рассчитываются по формулам, приведенным в описании каждого модуля.

2. **Самостоятельность выполнения:**
   Все задания должны быть выполнены строго самостоятельно. Задания, выполненные не самостоятельно, отклоняются.

3. **Материалы для сдачи:**
   * Исходный код разработанного узла на Python (`rclpy`).
   * Запись топиков симуляции ROS 2 Bag (`.db3` или `.mcap`) длительностью не менее 30 секунд:
     ```bash
     ros2 bag record /tf /clock /cmd_vel /odom /youbot/joint_states -o my_run.bag
     ```
   * Краткий отчет (PDF или Markdown) с формулами, описанием логики и скриншотами симуляции в Gazebo/RViz2.

## Модуль 1. Мобильные колесные роботы (по материалам Семинаров 1 и 2)

**Базовая платформа:** Дифференциальный колесный робот ([`basic_mobile_robot`](src/basic_mobile_robot/)) в ROS 2 и Gazebo Classic.  
**Среда выполнения:** ROS 2 Humble, `rclpy`, RViz2, Gazebo Classic.  
**Основные топики робота:** `/cmd_vel` (скорость тележки), `/odom` (одометрия), `/scan` (2D-лидар), `/joint_states` (состояния колес), `/tf` (координатные фреймы).

Все алгоритмы реализуются студентом самостоятельно с нуля на Python (`rclpy` + `math`/`numpy`) без использования готовых высокоуровневых пакетов навигации (Nav2 и т.д.).

### Расчет индивидуальных параметров:
```python
STUDENT_ID = 20240185  # Ваш номер студенческого билета
PARAM_R = 0.60 + (STUDENT_ID % 7) * 0.10   # Базовый радиус / масштаб (м): 0.60 ... 1.20
PARAM_V = 0.20 + (STUDENT_ID % 5) * 0.05   # Линейная скорость (м/с): 0.20 ... 0.40
PARAM_L = 0.25 + (STUDENT_ID % 4) * 0.05   # Дистанция отступа / упреждения (м): 0.25 ... 0.40
```

## Модуль 2. Мобильный манипулятор KUKA YouBot (по материалам Семинаров 2 и 3)

**Базовая платформа:** Мобильный манипулятор KUKA YouBot ([`youbot_description`](src/youbot_description/)) — омни-база (Mecanum) + 5-DOF манипулятор.  
**Среда выполнения:** ROS 2 Humble, `rclpy`, Gazebo Classic (физика ODE, гравитация), RViz2.  
**Основные топики робота:** `/youbot/cmd_vel` (скорость базы), `/youbot/odom` (одометрия), `/youbot/set_joint_trajectory` (управление рукой с `frame_id: 'world'`), `/youbot/scan` (лидар), `/youbot/joint_states` (состояния шарниров).

Все алгоритмы управления омни-базой и сочленениями руки реализуются студентом самостоятельно с нуля на Python (`rclpy` + `math`/`numpy`).

### Расчет индивидуальных параметров:
```python
STUDENT_ID = 20240185  # Ваш номер студенческого билета
ARM_ANGLE_DEG = 15.0 + (STUDENT_ID % 6) * 5.0    # Угловая амплитуда / смещение руки (град): 15 ... 40
BASE_SPEED    = 0.20 + (STUDENT_ID % 4) * 0.05   # Скорость омни-базы (м/с): 0.20 ... 0.35
TARGET_DIST   = 0.80 + (STUDENT_ID % 5) * 0.10   # Базовая дистанция / радиус маневра (м): 0.80 ... 1.20
```

### Список вариантов Модуля 2:

| Вариант | Название задания | Исполнительный узел | Алгоритмическая задача студента (самописная реализация) |
|:---:|:---|:---|:---|
| **1** | **Программный секвенсор поз манипулятора (Keyframe Sequencer)** | Рука YouBot | Пошаговый циклический перевод руки через 4 ключевые позы, заданные в градусах (парковочная $\to$ готов к работе $\to$ наклон вперед $\to$ подъем), с расчетом шага интерполяции и плавной сменой позы каждые 3 секунды. |
| **2** | **Омни-маневр: проезд квадрата без разворота (Mecanum Strafe)** | База YouBot | Проезд роботом периметра квадрата $\text{TARGET\_DIST} \times \text{TARGET\_DIST}$ без поворота корпуса (вперед со скоростью `BASE_SPEED`, боком вправо, назад и боком влево) с контролем пути по `/youbot/odom` при $\omega_z = 0$. |
| **3** | **Орбитальный обход препятствия боком (Mecanum Orbiting)** | База YouBot | Движение базы YouBot по окружности радиуса `TARGET_DIST` со скоростью `BASE_SPEED` с непрерывным направлением оси $X$ в центр за счет сложения боковой скорости $V_y = \text{BASE\_SPEED}$ и вращения $\omega_z = V_y / R$. |
| **4** | **Гармоническая омни-траектория «Восьмерка» (Figure-8)** | База YouBot | Движение базы по траектории «восьмерка» за счет одновременной подачи гармонических скоростей $V_x(t) = \text{BASE\_SPEED}\cos(\omega t)$ и $V_y(t) = \text{BASE\_SPEED}\sin(2\omega t)$ с нулевой угловой скоростью $\omega_z = 0$. |
| **5** | **Наведение манипулятора на азимут цели (Arm Yaw Targeting)** | Рука YouBot | По заданным координатам цели $(x_g, y_g)$ расчет угла первого сустава $q_1 = \text{atan2}(y_g, x_g)$, плавный доворот сочленения `arm_joint_1` на рассчитанный угол и фиксация позы в симуляторе. |
| **6** | **Плавная S-образная интерполяция суставов (Smoothstep)** | Рука YouBot | Реализация функции гладкого перехода $s(\tau) = 3\tau^2 - 2\tau^3$ (где $\tau = t/T \in [0, 1]$) вместо линейной интерполяции для устранения динамических рывков звеньев при старте и торможении руки YouBot. |
| **7** | **Конечный автомат операции Pick & Place (FSM Pick & Place)** | База + Рука | Пошаговый FSM: 1) Подъезд базы вперед на расстояние `TARGET_DIST` по одометрии $\to$ 2) Опускание руки в позу захвата $\to$ 3) Пауза/сведение схвата $\to$ 4) Подъем руки $\to$ 5) Откат базы назад на `TARGET_DIST`. |
| **8** | **Горизонтирование схвата манипулятора (End-Effector Leveling)** | Рука YouBot | Узел изменяет углы плеча $q_2$ и локтя $q_3$ с шагом `ARM_ANGLE_DEG`, при этом угол запястья автоматически рассчитывается как $q_4 = -(q_2 + q_3)$, удерживая губки схвата строго параллельно плоскости пола. |
| **9** | **Челночное диагональное движение «Зигзаг» (Omni Zigzag)** | База YouBot | Поочередное омни-движение под углом $45^\circ$ вперед-вправо ($V_x = V, V_y = -V$) и вперед-влево ($V_x = V, V_y = V$) на расстояние `TARGET_DIST` с контролем пройденного пути по одометрии. |
| **10** | **Синхронный старт: движение платформы с раскладыванием руки** | База + Рука | При подаче скорости на базу $V_x = \text{BASE\_SPEED}$ манипулятор синхронно раскладывается из компактной позы в рабочую; при остановке базы рука плавно складывается обратно в исходное положение. |
| **11** | **Безопасная лидарная остановка YouBot (Lidar Safety Brake)** | База YouBot | Движение базы YouBot со скоростью `BASE_SPEED`. Мониторинг фронтального сектора лидара `/youbot/scan` ($\pm 25^\circ$): при обнаружении препятствия ближе $0.6$ м платформа плавно сбрасывает скорость до нуля. |
| **12** | **Калибровка пройденного расстояния омни-базы (Odometry Calibration)** | База YouBot | Прямолинейный заезд на расчетную дистанцию `TARGET_DIST`, сопоставление фактических координат по `/youbot/odom` с теоретическими и расчет масштабного поправочного коэффициента $k = S_{fact} / S_{theor}$. |
| **13** | **Программный фильтр допустимых углов руки (Joint Limits Guard)** | Рука YouBot | Узел-фильтр для траекторий манипулятора: проверка задаваемых углов на непревышение паспортных пределов YouBot из Семинара 3 ($q_{min} \le q \le q_{max}$) с автоматическим ограничением (clamping) и логированием предупреждений. |
| **14** | **Маятниковое гармоническое качание звеньев (Harmonic Motion)** | Рука YouBot | Формирование непрерывных синусоидальных колебаний плеча и локтя: $q_2(t) = q_{2,0} + A \sin(\omega t)$, $q_3(t) = q_{3,0} + A \cos(\omega t)$ с амплитудой `ARM_ANGLE_DEG` без превышения пределов суставов. |
| **15** | **ROS 2 Сервис пресетов конфигураций руки (Arm Preset Poses)** | Рука YouBot | Сервер пользовательского сервиса с именованными позами (`HOME`, `TRANSPORT`, `EXTENDED`, `PICK`), обеспечивающий плавный интерполированный перевод звеньев между заданными конфигурациями. |
