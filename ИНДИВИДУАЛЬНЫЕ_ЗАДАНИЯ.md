В данном документе приведены темы и требования к индивидуальным заданиям по курсу практического планирования движений и траекторий в ROS 2 Humble. Успешное выполнение индивидуального задания оценивается в **54 балла** за соответствующий модуль и освобождает от сдачи базовых лабораторных отчетов по семинарам этого модуля.

Основная цель индивидуального трека — самостоятельная программная реализация классических и современных алгоритмов планирования пути (Motion Planning) для мобильной колесной платформы (Модуль 1) и многозвенного манипулятора (Модуль 2).

  * Базовый трек: отчеты по Семинарам 2 и 3 (средний балл до 45).

## Правила выбора варианта и требования к выполнению

1. **Выбор варианта:**
   Рекомендуемый способ выбора уникального варианта — по номеру студенческого билета / зачетной книжки (`STUDENT_ID`):

   ```math
   \text{Variant} = (\text{STUDENT\_ID} \bmod 15) + 1
   ```

   *(в синтаксисе Python: `variant = (STUDENT_ID % 15) + 1`)*

   Каждому номеру варианта соответствует конкретный фундаментальный алгоритм планирования, который реализуется как в Модуле 1 (для колесной базы), так и в Модуле 2 (для манипулятора).

2. **Самостоятельность реализации:**
   Все алгоритмы планирования должны быть написаны студентом **строго самостоятельно на Python (`rclpy` + `math`/`numpy`)**. Использование готовых сторонних пакетов планирования (Nav2, MoveIt 2, OMPL) в качестве ядра решения запрещено. Задания, выполненные не самостоятельно, отклоняются.

3. **Требования к вычислительной скорости:**
   К алгоритмам не предъявляется жестких ограничений по скорости расчета в реальном времени. В зависимости от размерности пространства и выбранной сетки некоторые алгоритмы могут вычислять путь заметное время (от секунд до десятков секунд). Оценка времени расчета (`t_calc`) и обсуждение вычислительной сложности в отчете является обязательной частью работы.

4. **Материалы для сдачи:**
   * Исходный код разработанного ROS 2 узла на Python.
   * Запись топиков симуляции ROS 2 Bag (`.db3` или `.mcap`) длительностью не менее 30 секунд:
     ```bash
     ros2 bag record /tf /clock /cmd_vel /odom /youbot/joint_states -o my_run.bag
     ```
   * Краткий структурированный отчет (PDF или Markdown) с описанием алгоритма, оценкой времени расчета, анализом применимости и иллюстрациями работы в Gazebo/RViz2.

## Модуль 1. Планирование движения мобильной колесной базы (по материалам Семинаров 1 и 2)

**Базовая платформа:** Дифференциальный колесный робот ([`basic_mobile_robot`](src/basic_mobile_robot/)) в ROS 2 и Gazebo Classic.  
**Среда выполнения:** ROS 2 Humble, `rclpy`, RViz2, Gazebo Classic.  
**Основные топики робота:** `/cmd_vel` (скорость тележки), `/odom` (одометрия), `/scan` (2D-лидар), `/tf` (координатные фреймы).

**Постановка задачи:**  
Робот стартует в начале координат (0, 0). Необходимо спланировать траекторию или путь в целевую точку (x_goal, y_goal) в обход заданных препятствий с использованием назначенного алгоритма, после чего отработать построенный маршрут платформой в симуляторе Gazebo (прямой выдачей скоростей `/cmd_vel` либо через следование по путевым точкам регулятором).

### Расчет индивидуальных параметров:
```python
STUDENT_ID = 20240185  # Ваш номер студенческого билета

# Целевая точка назначения (м):
TARGET_X = 2.0 + (STUDENT_ID % 5) * 0.25   # 2.00 ... 3.00 м
TARGET_Y = 1.5 + (STUDENT_ID % 4) * 0.25   # 1.50 ... 2.25 м

# Координаты цилиндрического препятствия (м):
OBS_X = 1.0 + (STUDENT_ID % 3) * 0.20      # 1.00 ... 1.40 м
OBS_Y = 0.7 + (STUDENT_ID % 3) * 0.15      # 0.70 ... 1.00 м
OBS_R = 0.35                               # Радиус зоны безопасности препятствия (м)
```

## Модуль 2. Планирование перемещений манипулятора KUKA YouBot (по материалам Семинаров 2 и 3)

**Базовая платформа:** Мобильный манипулятор KUKA YouBot ([`youbot_description`](src/youbot_description/)) — омни-база (Mecanum) + 5-DOF манипулятор.  
**Среда выполнения:** ROS 2 Humble, `rclpy`, Gazebo Classic (физика ODE, гравитация), RViz2.  
**Основные топики робота:** `/youbot/cmd_vel` (скорость базы), `/youbot/odom` (одометрия), `/youbot/set_joint_trajectory` (траектория манипулятора, `frame_id: 'world'`), `/youbot/joint_states` (состояния шарниров).

**Постановка задачи:**  
Манипулятор стартует из исходной конфигурации (Home: все углы равны 0 либо устойчивая поза из Семинара 3). Необходимо переместить фланец/схват манипулятора в целевую точку пространства (x_goal, y_goal, z_goal) (либо перевести сочленения в целевую конфигурацию `q_goal`), обойдя заданную пространственную зону препятствия (сферу коллизии в рабочем пространстве), используя **тот же алгоритм планирования**, что и в Модуле 1.

> [!NOTE]
> **Особенности планирования для манипулятора:**  
> Для многомерных систем (C-space размерности от 3 до 5) алгоритмы на сетках (`A*`, Дейкстра) могут требовать ощутимого времени расчета или дискретизации ограниченного подпространства основных сочленений (q₁, q₂, q₃), тогда как сэмплирующие алгоритмы (RRT, `RRT*`, PRM) масштабируются эффективнее. Любое время вычислений допустимо — ключевым результатом является сравнительный анализ поведения алгоритма в отчете.

### Расчет индивидуальных параметров:
```python
STUDENT_ID = 20240185  # Ваш номер студенческого билета

# Целевые декартовы координаты фланца манипулятора (в метрах относительно base_footprint):
TARGET_PX = 0.25 + (STUDENT_ID % 4) * 0.04   # 0.25 ... 0.37 м
TARGET_PY = -0.15 + (STUDENT_ID % 5) * 0.08  # -0.15 ... 0.17 м
TARGET_PZ = 0.20 + (STUDENT_ID % 4) * 0.05   # 0.20 ... 0.35 м

# Сферическая зона препятствия в рабочей зоне манипулятора:
OBS_SPHERE_X = 0.20                          # Координата X центра сферы (м)
OBS_SPHERE_Y = 0.00                          # Координата Y центра сферы (м)
OBS_SPHERE_Z = 0.22                          # Координата Z центра сферы (м)
OBS_SPHERE_R = 0.08 + (STUDENT_ID % 3) * 0.02 # Радиус сферы препятствия: 0.08 ... 0.12 м
```

> **Подсказка по кинематике для проверки коллизий (FK):**  
> Координаты звеньев манипулятора YouBot вычисляются через прямую кинематику: базовый поворот q₁ вокруг оси Z, звенья руки имеют длины L₁ ≈ 0.147 м (высота плеча), L₂ ≈ 0.155 м (плечо), L₃ ≈ 0.135 м (предплечье), L₄ + L₅ ≈ 0.218 м (кисть и схват). Для проверки столкновения со сферой достаточно проверять расстояния от центров звеньев до центра сферы (x_obs, y_obs, z_obs).
